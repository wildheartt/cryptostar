# 🚀 Криптостар — Мониторинг Криптовалют

![React](https://img.shields.io/badge/React-18-blue?logo=react)
![Redux](https://img.shields.io/badge/Redux-9-purple?logo=redux)
![Ant Design](https://img.shields.io/badge/Ant%20Design-5-green?logo=antdesign)

**Криптостар** — это веб-приложение для отслеживания топ-100 криптовалют 📊 с детальной аналитикой, графиками и актуальной рыночной информацией.

## 🌟 Особенности

- 🏆 Топ-100 криптовалют в реальном времени
- 📈 Интерактивные графики цен (Chart.js)
- 💰 Детализация рыночной капитализации
- 🔍 Поиск и фильтрация криптовалют
- 🕒 Исторические данные
- 📱 Адаптивный дизайн (Ant Design)
- ⚡ Быстрое обновление данных (Axios)

## 🛠️ Технологии

- ⚛️ React 18 + React Router
- 🔄 Redux Toolkit для управления состоянием
- 💅 Ant Design v5 — UI библиотека
- 📊 Chart.js + react-chartjs-2 — визуализация данных
- 🌐 Axios — HTTP-запросы
- 🕰️ Moment.js — работа с датами
- 📦 Babel

## 🚀 Быстрый старт

1. **Клонировать репозиторий**
   git clone https://github.com/your-username/cryptostar.git
   cd cryptostar

2. **Установить зависимости**
   npm install

3. **Запустить приложение**
   npm start

4. **Сборка для production**
   npm run build

5. **Тестирование**
   npm test # Запуск тестов
   npm run lint # Проверка стиля кода
   npm run format # Форматирование кода
